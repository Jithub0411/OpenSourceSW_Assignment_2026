# 오픈소스SW개론 출석특례 대체과제

## 1. 과제 소개

출석특례 학생들을 대상으로 강의에서 배운 내용을 바탕으로 공통 데이터를 처리하고,
그 과정 전체를 GitHub 저장소 하나에 기록해야 함.

기간: 공지일로부터 2026년 12월 14일(월)까지, 마일스톤 5회

Part A:  리눅스 데이터 처리
Part B:  VIM 편집 
Part C:  Docker 이미지
Part D:  Git-GitHub 운영과 문서, 라이선스

주의사항: 하나의 GitHub 저장소에서 작업 과정과 결과를 관리해야 한다.
